# Oropharyngeal microbiome in interstitial lung disease

Scripts for the paper titled 'Metagenomic Profiling Reveals Distinct Oropharyngeal Dysbiosis and Altered Functional Potential in Interstitial Lung Disease with Superimposed Infection'

## Scripts

- `Figure1_diversity_composition.R` – Figure 1: Microbial diversity and community structure
- `Figure2_LEfSe_analysis_and_clinical_correlations.R` – Figure 2: LEfSe analysis and clinical correlations
- `Figure3_dysbiosis_pathways.R` – Figure 3: Functional metabolic pathway alterations
- `Figure4_ARG_profiles.R` – Figure 4: Antimicrobial resistance gene (ARG) profiles
- `Figure5_VF_profiles.R` – Figure 5: Virulence factor (VF) profiles
